## Compact state and correctness

Q callback identities each own their reusable global-vertex scratch and process at most one root until all descendants join. A root may create at most b-1 child snapshots, using a shared strong-CAS credit counter. Each child owns current-root P/C1/C2/X/XBK/recovery stacks, neighbor counts, fresh maximality-check scratch over current l, and its output count. Parent X/XBK pointer alias is preserved. Shared adjacency ownership is the original Graph shared_ptr; matrix, block and original-ID references remain alive and unchanged until every strict join returns. The stream only then clears/reuses them. Helping another stream cannot introduce more than Q live root frames.

The kSearch first-exclusion branch versus ordered include-prefix continuation, candidate-pivot include/exclude branches and plex-pivot first-exclusion versus ordered include-prefix cases remain complete and disjoint. Global maximality checks remain unchanged. A cloned child restores only child-owned new removals; nevertheless compact sets copy all current b member/position entries to retain removed suffixes. Their flag words are copied verbatim and masked above b, preserving fakeRemove flags rather than rebuilding membership from only the active prefix. Stack copies retain the live prefix with exact capacity b. Historical stream capacity is never copied. Parent permutations need not match serial after child completion, so there is no claim of identical search trees or actual node counts.

## Work, span and space

Let N be the peeled graph size, D2=sum degree(v)^2, b_i/l_i the current root universes, R<=N the roots, and k the problem parameter. P004 R2 ensures Q*N<=N+D2 dense initialization and clears candidate membership only through the current root universe. Each snapshot is O(b+l) work/capacity. At most b-1 snapshots and O(b^2) total strong-CAS contention failures cost O(b^2+b*l), charged to each root's unconditional pair-matrix writes and block-by-left scans. Exhausted-budget checks are O(existing branch calls). All primitive lookup is dense array access: the P001 expected-hash assumption is absent. This is a common-parameter work bound, not per-input equality to a particular serial pruning order.

Span includes serial peeling/degeneracy, O(N) per-stream dense initialization, the atomic root-claim chain O(R), every serial prefix/recovery/copy/CAS path, and the largest unsplit subtree. A conservative actual-assignment bound is preprocessing + O(N+R+log(Q+1)) + max_s sum_{roots assigned to s} D_i. No logarithmic enumeration span or automatic ideal speedup is claimed. P1 uses the same native binary and skips snapshots.

Global auxiliary space includes graph storage, Q*N dense scratch, retained per-stream historical matrix/vector capacities, and sum over at most Q live roots of O(b^2+b*l+b^2*k) snapshot/recovery state. The b^2*k term conservatively includes up to b live task frames each with existing O(b*k) serial recovery vectors; fixed k reduces it to O(b^2). Retained vector capacity must be included separately rather than equating it to the current b. Actual RSS remains required; no unmeasured memory-scalability claim is made.

No new machine/graph/time threshold is introduced: only problem inputs, workers, the previously justified Q rule and structural b-1 credits. Diagnostics report exact total snapshots and cumulative base snapshot capacity, excluding allocator/object/temporary vector overhead; this is not peak memory or exact copied bytes.
